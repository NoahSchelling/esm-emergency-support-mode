# hackathon_tomato

## 公的情報を優先してください

！！仮の値！！ このリポジトリの成果物は、気象庁などの公的な発表を中継するだけのものです。独自の予報・警報は出しません。避難や身の安全にかかわる判断は、気象庁・自治体などの公的な発表と指示を優先してください。成果物の表示は、古い・止まっている・間違っている可能性があります。
