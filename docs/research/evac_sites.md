## 3. 利用条件

### 3.1 国土地理院コンテンツ利用規約

- **確認済み（文書）** 令和 7 年 11 月 20 日改正。特段の記載がない限り公共データ利用規約（第 1.0 版）（PDL1.0）を適用する。（<https://www.gsi.go.jp/kikakuchousei/kikakuchousei40182.html>）
- **確認済み（文書）** 出典の記載例：「出典：国土地理院ウェブサイト　（当該ページのURL）」。編集・加工して使うときは、出典とは別に、加工したことを書く。例：「『○○データ』（国土地理院） （当該ページの URL） をもとに○○株式会社作成」。加工した情報を、国土地理院が作ったかのような態様で公表・利用してはいけない。（同上）
- **確認済み（文書）** 第三者の権利、個別の法令（測量法の基本測量成果・公共測量成果など）の制約がある場合の注意がある。指定緊急避難場所データは、規約のページの例には挙がっていない。（同上）
- PDL1.0 の条文（複製・公衆送信・翻案などを、出典を書けば自由にできる。商用も可）は、`jma_data.md` の 4.1a で読んだもの。

### 3.2 指定緊急避難場所・指定避難所データの「ご利用上の注意」

**確認済み（文書）**（入口のページ、免責事項のページ、ダウンロードの zip に入る `ご利用上の注意.txt` の 3 か所で同じ内容）。国土地理院コンテンツ利用規約のほか、次の注意に同意した場合だけ使う。

1. 市町村長が指定した場所を、各市町村が登録したもの。最新でない場合や未掲載の場合があるため、最新かつ詳細の状況は必ず当該市町村に確かめる。
2. 「指定緊急避難場所」と「指定避難所」の違い、指定緊急避難場所が災害の種別ごとに指定されていることを理解して使う。
3. 随時更新されるので注意する。
4. このデータを使った情報を第三者に提供する場合は、1〜3 の注意が正確に伝わるよう留意する。

原文は `modules/evac/data/shizuoka_evac.json` の `notices` に書き写した。

### 3.3 リポジトリに置いてよいか（判断）

- PDL1.0 は、出典を書けば複製・加工・公衆送信を認めている。指定緊急避難場所データに、これを外す個別の記載は見当たらなかった。ダウンロードサイトは、CSV と GeoJSON を誰でも取得できる形で出している。
- 「ご利用上の注意」は、第三者への提供を禁じていない。注意を正確に伝えることを求めている。
- よって、**静岡県分を加工した JSON をリポジトリに置き、出典・加工の表記・注意の 1〜3 を、README、データの中、画面に出す**ことにした。
- 置かない案（手元で作るスクリプトだけをコミット）も考えた。データがないと試験も画面も動かず、作り直しの手順が要る。条件を満たせば置けると読めるので採らなかった。スクリプト（`modules/evac/tools/build_evac_data.py`）は、置いたデータを作り直すためにもコミットする。

### 3.4 出典の書き方（このプロジェクトで使う文）

- 出典：国土地理院ウェブサイト（指定緊急避難場所データ）<https://hinanmap.gsi.go.jp/index.html>
- 加工の表記：「指定緊急避難場所データ」（国土地理院）（<https://hinanmap.gsi.go.jp/index.html>）をもとに本プロジェクトが作成（静岡県分の抽出、項目の選択、災害の種別の符号化、座標の丸め）。国土地理院が作成したものではありません。

- 災害の種別ごとの数：洪水 1,475、崖崩れ・土石流・地滑り 1,299、高潮 241、地震 2,102、津波 1,179、大規模な火事 838、内水氾濫 623、火山現象 304。

## 5. データに欠けがありうること（README と画面に書く内容）

- 市町村が登録し、公開に同意したものだけが含まれる（2 章）。
- 最新でない場合、載っていない場合がある（3.2 の 1）。
- 静岡県のデータだけを持つ。県境の近くでは、隣の県の避難場所が候補に出ない。
- 画面では、候補がないときに「近くにない」ではなく「データの中に見つからない」と書く（BW-S3）。

## 6. 公的なデータが取れないときのフォールバック先（民間のサイト）

画面が公的なデータ（このデータ）を読めないとき、または候補が見つからないときに、利用者が自分で確かめに行ける先として、リンクだけを出す。位置や入力を URL に入れない（送らない）。**どれを出すかは人が決める（！！仮の値！！）。**

| 順 | 先 | 種類 | 調べたこと |
| --- | --- | --- | --- |
| 1 | 市町村の発表・ハザードマップ | 公的 | 市町村ごとに URL が違うので、この回はリンクを持たない。画面の文で「市町村の発表を確かめてください」と出す |
| 2 | 地理院地図（指定緊急避難場所の層） | 公的 | 説明のページにある地理院地図へのリンク。地図なので通信量が多い |
| 3 | Yahoo!天気・災害「避難場所マップ（静岡県）」<https://crisis.yahoo.co.jp/map/?pref=22> | 民間 | **確認済み（取得）** 避難情報のページからのリンク。地図。データの出典は**未確認** |
| 4 | Yahoo!天気・災害「避難情報・避難所の開設情報（静岡県）」<https://crisis.yahoo.co.jp/evacuation/22/> | 民間 | **確認済み（文書）** L アラートを通じて自治体が発表する情報と、株式会社レスキューナウが独自に取材した情報を載せている。「掲載されていない情報がある場合がある」「各自治体が発表する情報もあわせて確認」と書いている。避難場所の位置の一覧はない |

- 民間を選んだ理由：L アラート（自治体の発表の共有基盤）の情報を載せていて、出典を明示している。大手で、災害時にも運用が続く見込みが高い（推測）。
- 画面では「民間のサイトです。公的な発表ではありません」と添え、公的な先（1・2）より下に出す（BW-S2）。
- 却下した案：民間のサイトから避難場所のデータを取り込む案。利用規約で取り込みが認められているかを確かめていない。公的なデータだけを方向の計算に使う（BW-S1）。

## 8. 偏角（磁北と真北のずれ）の出典

- **確認済み（文書）** 国土地理院「近似式から求める」（2020.0 年値）（<https://vldb.gsi.go.jp/sokuchi/geomag/menu_04/index.html>）：

  D = 8°15.822′ + 18.462′Δφ − 7.726′Δλ + 0.007′(Δφ)² − 0.007′ΔφΔλ − 0.655′(Δλ)²

  Δφ = φ − 37°、Δλ = λ − 138°（度）。D は真北を基準に反時計回り（西回り）を正とする。日本周辺の磁場を大局的に近似した式で、地域的な磁気異常は反映されない。離島では精度が下がる。ページの計算例（東京、北緯 35.68 度・東経 139.70 度）は 7°36.5′（西偏）。この計算例をテストで再現している。
- **確認済み（文書）** 磁気図のページ：偏角一覧などは国土地理院技術資料で、申請不要、国土地理院コンテンツ利用規約に従う。商用利用も可。（<https://www.gsi.go.jp/buturisokuchi/menu03_magnetic_chart.html>）
- 2020.0 年値（2020 年 1 月 1 日の値）なので、2026 年にはずれている。ずれの大きさは**未確認**（地磁気は時間で変わる、とページに書かれている）。静岡県では偏角は約 7〜8 度（西偏）で、補正しないときの誤差よりは小さいと考えている。端末のコンパスの誤差（金属や車の近く）のほうが大きくなりうる（`docs/proto/evac.md`）。
