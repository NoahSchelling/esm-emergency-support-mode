## 1. 取得できなかった理由

このセッション（クラウドの実行環境）のネットワーク設定で、次のホストへの接続が拒否された（2026-11-04、プロキシが CONNECT に 403 を返した）。

- `www.data.jma.go.jp`（Atom フィードと XML 電文の置き場所）
- `www.jma.go.jp`（気象庁ホームページ、`/bosai/` 以下の JSON）
- `xml.kishou.go.jp`（防災情報 XML の技術資料）

Web ページを読む機能（WebFetch）でも、`www.data.jma.go.jp` と `xml.kishou.go.jp` は名前解決できなかった。

そのため、依頼の 1・2・5（実際の取得、XML の構造、応答ヘッダの確認）は実施できていない。サンプルも保存していない（`data/samples/` は空のまま。推測で作ったサンプルは置かない）。

続きをするには、実行環境の設定（Network access）で上の 3 ホストを許可する必要がある。手順：<https://code.claude.com/docs/en/cloud-environments#network-access>

## 3. 調べること 2：地震情報と気象警報の XML の構造

### 未確認（すべて）

実物を 1 件も取得できなかったため、構造の説明はまだ書けない。事前知識では、防災情報 XML は次の 3 つの部分でできている。確かめるときの観点として書き留める。

| 部分 | 事前知識による中身（未確認） |
| --- | --- |
| Control | 電文の種類、運用の種別（通常／訓練／試験）、発表した官署、送信時刻 |
| Head | 見出し、発表時刻、効力の始まり、情報の種類（発表・訂正・取消など）、イベント ID、版番号 |
| Body | 情報の本文。地震なら震源・規模・各地の震度、警報なら地域ごとの警報・注意報の種類と状態 |

確かめること：

- 発表時刻を表す要素はどれか（送信時刻・発表時刻・効力の始まりの違い）。
- 対象地域の表し方（地域名と地域コード。コード表の出典）。
- 「訓練」「試験」の電文を見分ける方法。**本番の画面に訓練・試験の電文を出さない処理が必要になる見込み**（BW-S1 にかかわる）。

## 4. 調べること 3：「取消」「訂正」「解除」の表し方

### 未確認（すべて）

事前知識では次のようになっているが、仕様書も実物も確認していない。

- 「訂正」「取消」：Head の中の「情報の種類」を表す要素の値として表す。取消のときは、同じイベント ID の前の電文を打ち消す。
- 「解除」：電文の種類ではなく、警報・注意報の本文で、地域ごとの状態として表す（「発表」「継続」「解除」など）。

確かめること：

- 上の値の一覧と、それぞれの意味の定義（仕様書の該当箇所）。
- 取消の電文が来たとき、どの電文を打ち消すのかの決まり（イベント ID と版番号の扱い）。
- 「解除」と「警報なし」の違い。**BW-S3（新しい警報がないことを安全と表示しない）にかかわる。**「解除」を受け取っても「安全」とは表示しない設計にする。

## 8. 次の回で確かめる手順

ネットワークの許可が出たら、次の順で確かめる。結果は「確認済み」として、この文書に出典 URL と取得日時を付けて書き直す。

1. 技術資料の入り口（`xml.kishou.go.jp`）と、開発者向けページ（`https://www.data.jma.go.jp/developer/index.html`）を読み、フィードの種類・URL・更新間隔・アクセスの注意を書き写す。
2. 4 種類のフィードを取得し、`entry` の数、`updated` の間隔、`entry` の中の電文の種類（`title`）を数える。
3. 地震火山のフィードから地震情報を 1 件、随時のフィードから気象警報を 1 件取得し、構造を説明する。小さいものを `data/samples/` に保存し、取得元 URL と取得日時を README か同じ場所の説明ファイルに書く（3 件まで）。
4. 仕様書で「訂正」「取消」「解除」の定義を読む。
5. 各 URL に対して、別のサイトからの読み込みを想定した要求（`Origin` ヘッダを付けた要求）を送り、応答ヘッダの `Access-Control-Allow-Origin` を記録する。
6. 利用規約、ご利用上の留意事項（ryuui.pdf）を読み、出典の書き方と加工の注意を書き写す。

5 のための確認コマンドの例（`Origin` には自分のサイトの URL を入れる。ここでは例示用のドメインを使う）：

```bash
curl -sS -o /dev/null -D - -H "Origin: https://example.com" https://www.data.jma.go.jp/developer/xml/feed/eqvol.xml
```
