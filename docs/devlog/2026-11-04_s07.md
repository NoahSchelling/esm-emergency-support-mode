# 2026-11-04 s07

## 目的

気象庁防災情報 XML 以外の公的な防災データ（河川・ダム、キキクル、ハザードマップ、地形・標高、指定緊急避難場所、放射線モニタリング、熱中症警戒アラート、その他）について、取得方法と利用条件を調べ、`docs/research/other_data.md` にまとめる。2026 年の防災気象情報の名称の変更を一次情報で確かめる。

## 決めたこと（理由・却下した案）

- **区分は依頼の 4 区分（1〜4）で付け、「条件付き」の注記を足した。** キキクルのタイルと JSON は無償・リアルタイムで ACAO もあるが、仕様書がない。熱中症の CSV は運用期間中だけ配信される。1 か 2 かを言い切ると誤解を生むので、区分のあとに条件を書いた。
- **川の防災情報の画面の内部 JSON は使わない。** 取り扱い上の注意に「ツール等による定期的なデータ収集は…お控えください」と明記されているため。数値が必要なら、有償の水防災オープンデータ提供サービスになる。
- **RAMIS（放射線）の内部通信は調べなかった。** 画面の内部 API を探すことは画面からの自動取得に近く、依頼の「スクレイピングはしない」に反するため。区分 4（確認できず）とした。
- **J-SHIS の応答はサンプルにしなかった。** 利用規約が地震動予測地図データの「そのままの複製・頒布」を禁じており、公開リポジトリに置くと頒布に当たるため。
- **サンプルは画像を避けた。** 検査スクリプトは画像のメタデータを検査しないため。テキストの 3 件（キキクルの時刻の一覧、暑さ指数の予測値 CSV、ハザードマップの WMTS メタデータ）にした。
- **熱中症のアラートは「発表の有無・時刻・地域」の中継にとどめる方針を書いた。** アラートの CSV と環境省のページには身を守る行動・応急処置の説明があり、そのまま出すと BW-S4（医療の助言を実装しない）に触れる恐れがあるため。

## 試して分かったこと（失敗を含む）

- 無償・機械可読・リアルタイム（区分 1）は少ない。河川水位・ダム放流・避難指示の数値は、有償か確認できなかった。一方、地理院タイル形式の静的データ（ハザードマップ、標高、避難場所、伝承碑）は ACAO `*` で画面から直接読める。
- 熱中症の予測 CSV は、提供期間（10 月 21 日まで）のあとも 10 月の予測を HTTP 200 で返した。気象庁の古い JSON（`jma_data.md` 6 章）と同じ「古いデータがエラーにならずに返る」型。
- 2026 年 5 月 29 日に新たな防災気象情報の運用が始まった。名称は「レベル○（災害種別）＋（注意報／警報／危険警報／特別警報）」。土砂災害警戒情報はレベル 4 土砂災害危険警報、洪水警報・注意報は廃止、キキクルに大雨キキクルが加わった。指定河川洪水予報の旧名称との 1 対 1 の対応は一次情報で確かめられなかった。
- 遮断：`www.river.or.jp` と `www.jmbsc.or.jp` はこの環境のプロキシが CONNECT を 403 で拒否した。回避はしていない。`www.gsi.go.jp` は curl が古い TLS の再ネゴシエーションを拒否したので、Web 取得の道具で読んだ（要約なので原文の全文は見ていない）。
- **個人語の検査は未実施。** 環境変数 `ESM_DENYLIST_FILE` が未設定で、フックがそのことを表示した。
- 日付：作業した時刻は日本時間で 2026-11-05 の 04 時台だった。開発ログのファイル名は依頼で指定された `2026-11-04_s07` にした。調査メモの調査日は日本時間の 2026-11-05 と書いた。

## Claude の使い方（どの機能を何のために）

- Bash（curl）：配信 URL の取得、応答ヘッダ（ACAO、Last-Modified、Cache-Control）の確認、PDF・docx からの文字の取り出し。ダウンロードしたものはスクラッチパッドの専用ディレクトリに置き、Python は `-I` で動かした。
- WebSearch：配信事業や利用規約のページの場所を探すため。結果の要約は使わず、見つけたページを取得して本文を読んだ（L アラートだけは一次情報を読めず「未確認」とした）。
- WebFetch：curl で TLS 接続できなかった国土地理院のページと、JavaScript で描画するページを読むため。
- Claude Code のフック：Bash のコマンドに `push` の語（URL の一部）が入ったときにも検査が走り、未プッシュのコミットがないことと、個人語の検査が未実施であることを表示した。

## 誤り記録

- 国土数値情報の全国版 zip（約 353MB）の存在を確かめるのに、ヘッダだけでなく GET で全体をダウンロードしてしまった（中身は捨てた）。影響は通信量と時間だけ。大きいファイルは HEAD か Range 指定で確かめるべきだった。
- 原子力規制委員会のページを、最初は User-Agent を付けずに取得し、サーバー側から 403 が返った。ほかの取得と同じ User-Agent を付けて取り直した。
- `README.md` の出典の表に行を足すとき、表のあとの空行の下に足してしまい、表が切れた。すぐに見直して直した。

## l4b へ戻す学び

- 「公的・無償」でも、数値のリアルタイム配信は有償の別事業になっていることが多い（河川）。画面が無償で見られることと、機械で受けてよいことは別に確かめる。
- 公開リポジトリにサンプルを置く前に、「そのままの再配布」が許されているかを規約で確かめる（J-SHIS は禁止）。
- 季節運用のデータ（熱中症）は、期間外にも古いファイルが返る。期間外の挙動を確かめないと「最新」と誤表示する。
