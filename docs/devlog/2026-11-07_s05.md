# 2026-11-07 s05

## 目的

PC で s04 の画面を見た人からの指摘で、避難者の画面を全体的に作り直す。

前提（人から）：この画面を開くのは、実際の災害でエリアメールを受け取った人。平常心を失って次の行動を探しているので、文章はほとんど読めない。単純な文字と直感的な図・記号が行動を左右する。s04 までの文字量は支援者向けだった。

指示された修正：

- ヘッダーのタイトルを「ESM 緊急支援モード」にし、メニューをハンバーガーメニューにする。
- 人が別の場所で作ったデザインのサンプル集（リポジトリの外の HTML）の「B. モダン Bento Grid」を参考に、デザインを全面的に見直す。
- デモに関する表示（「過去の記録の再生」「模擬データを含みます」など）を画面のいちばん下へ移し、「デモモードの情報」という見出しの、黒い枠・白い背景の箱にまとめる。
- 「公的な発表と指示を優先してください」を「公的な情報を優先してください」に変え、画面の下のほうへ移す。
- メイン画面は、向いている方角と避難目標の図を大きく、位置を固定して出す。向いている方角は 1 秒ごとに更新する。
- 日時は年を省き「3.11 14:46」の形にする。
- 方角の図の上には一行だけ出す（優先は 津波＞地震＞その他の災害）。一行の情報は右端から定位置へスライドして入る。1 位でなくなった情報は方角の図の下へ移る。書き方は 津波＝「津波 〇m、〇〇港、到着 xx:xx、予想／実測」、地震＝「地震 最大震度〇、〇〇県〇〇地域、M〇、深さ〇km、予想／実測」、その他の気象警報。
- 方角の図のすぐ下に「現在地の標高 約〇m」を常に出す。
- 「受け取っている範囲では、この地域への注意報・警報はありません。発表がないことは、安全という意味ではありません。」を「身の安全を確保してください」にする。
- 小さな文字は要約して折り畳み、行頭に「▶」を出す。
- 「確かめる先」の「市町村の発表とハザードマップを確かめてください。」を消し、各サイトはサイト名とリンクだけにする。
- 「引き継ぎメモ」を「伝達メモ」にする。
- メニュー：各項目の行頭に「▶」（開閉が分かる）。二択はラジオボタン（押したらすぐ適用）。デモの ON／OFF はトグルスイッチ、場所はドロップダウンリスト。

## 決めたこと（理由・却下した案）

人の指示どおりに実装したもの：上の各項目。

自分で決めたこと：

- **Bento Grid の取り入れ方**：白い背景、細い枠（#e5e5e5）・角丸 24px・薄い影のカード、等幅の小さなラベル、丸いピル。サンプルの 6 色のうち、緑は使わない（BW-S3）。サンプルが読み込む Tailwind と Google Fonts は使わず、CSS だけで書いた（外部への通信を増やさないため）。幅 720px 以上では 2 列（方位の図が左、標高・ほかの情報が右）。サンプルの非対称の赤い外枠は取り入れず、s04 で決めた 10px の外枠のまま。
- **一行の情報の書き方**：先頭は「津波」ではなく、発表の種類（「大津波警報」「津波注意報」など）にした。外枠の色だけでは種類が分からないため。例：`大津波警報 10m以上、静岡県、予想`。予報区の発表には港の名前と到着時刻がないので、分からない項目は省く。観測（実測）は観測点の名前を入れる（`津波 9.3m以上、相馬、実測`）。
- **地震のデモの値**：福島県の記録に、記録で確かめられたもの（三陸沖、のちに M9.0／緊急地震速報（警報）／小名浜 333cm・相馬 9.3m以上の観測）だけを入れた。最大震度と震源の深さは、`docs/research/demo_records.md` で確かめていないので入れていない（気象庁の PDF を開こうとしたが、手元で読めなかった）。現在位置のモードでは、試作 C-A が地震の電文をまだ読まないので、地震の行は出ない（次の段階）。
- **デモの印**：デモの表示を下へ移すと、上から「模擬」が見えなくなる。そこで一行の情報に「模擬」「記録の再生」のピルを付けた。知らせとサブ画面 1 の「【模擬】」などはそのまま。
- **方位の図**：図は一度だけ作り、1 秒ごとに向きだけを変える（大きさと位置は固定。回転は短い向きへ 0.6 秒で動く。文字盤の「北東南西」は常に正立）。矢印の条件は s04 までと同じ（`modules/evac/` が向きを認めたときだけ）。避難目標があって向きを認められないときは、文字盤を北が上で止め、避難場所を点と点線で示す（矢印にしない）。向いている方角が分かれば縁に白抜きの印で出す。避難目標がないときは、向きが分かれば文字盤が回るただの方位磁針。避難者の画面の描き直しを 0.25 秒ごとから 1 秒ごとにした。
- **向いている方角の文字**：8 方位と度（「北東 45°」）。位置がまだないときは、偏角に日本の中ほど（北緯 36 度・東経 138 度）の値を使う（この文字のためだけ。矢印の計算には使わない）。
- **方向の文**：図の下は「直線 約 280 m 北北西」のように短くし、「北から約 341 度（北北西）の方向」の全文は折り畳みの中へ。
- **「身の安全を確保してください」**：一行の情報（発表がないとき）、サブ画面 1 の一覧と状態の行に使う。「安全です」という主張ではなく行動の指示なので、BW-S3 に反しないと判断した。受け取れていないとき・地域を選べないときは、そう書く（「身の安全を確保してください」にはしない）。`modules/alert/` の文は変えず、画面で差し替えた。
- **「確かめる先」**：サイト名とリンクだけにした結果、民間のサイトに付けていた「民間のサイトです。公的な発表ではありません」も消えた。サイト名（Yahoo!天気・災害）で民間と分かる、と判断した。人に見てほしい点。
- **伝達メモ**：画面の文だけでなく、メモの見出し、Skill（`skills/handoff-interview/`）、README、CLAUDE.md の BW-S4 の文も「伝達メモ」にそろえた（メモを Skill に渡すため、名前がずれると困る）。
- **メニュー**：画面の上に重なるパネルにした。役割と同意はラジオボタン（押すとすぐ適用）。役割とデモの ON／OFF を変えると、変化が見えるようにメニューを閉じる。
- 却下：一行の情報を横に流れ続けるテロップにする案（読めない人には動き続ける文字はかえって読みにくい。入るときに一度だけスライドする）。

### 追加：方位の図をヘディングアップに（人の指示）

人から「方角表示を North Up から Heading Up に変えたい。スマートフォンが向いている方向を上矢印で固定し、方角の円と避難目標が回る」と指示があった。

- それまでも、向きを認めたときは文字盤が回っていたが、中央の矢印は「避難場所の方向」を指していた。PC にはコンパスがないので、北が上の図しか見えていなかった。
- 中央の上向きの青い矢印を「向いている方向」として固定し、方角の円と避難目標の印（オレンジの丸に「避」）が回るようにした。目標の印の角度は、モジュールの `arrow_deg`（端末の傾きも考えた、画面の上での方向）を使う。
- 決めたこと：向きを認められないときは、ヘディングアップにしない（北が上の図、上向きの矢印なし）。確かめていない向きで目標の印を回すと、間違った方向を指す矢印と同じになるため（s04 までの「間違った矢印は、ないより悪い」の方針）。
- 確かめ：Playwright で iPhone のコンパスを偽って、向き 60 度・200 度で画面を撮った。ブラウザのテストに、ヘディングアップ（矢印は固定、円は向きの分だけ逆に回る、目標の印は `arrow_deg`）と、校正されていないときに北が上に戻ることを足した。

### 追加：標高の注意書き、実測の高さ、静岡県のデモ（人の指示、2026-11-08）

- 標高の注意書き：津波の高さ以下なら「⚠️津波よりも下にいます」、上限がない（10m以上など）なら「⚠️津波上限が予測不能です」。いつも出す文は「津波は予想より高くなる場合あり。」。
- 実測：観測された津波の高さも使い、**予想と実測の高いほう**と標高を比べる（人の理由：観測されてから届くまで、まだ避難できる時間がある。避難をあきらめさせない）。「9.3m以上」のような「以上」「超」は上限なしとして扱う。観測の行は、気象庁が津波警報に使う高さの区分（1m以下・3m以下・3m超）の色と、出ている津波の発表の色の高いほうで色分けした。
- 外枠（画面全体の警告）：最初は、BW-S1（外枠は公的発表の種類から決める）を外れるため変えずに人に確かめた。人の答えは「外枠も上げる」。`modules/alert/` の `alertState` に `observed`（最寄りの津波予報区で観測された最大の高さと、その区分のレベル）を足し、発表のレベルより高いときだけ外枠を上げる（下げない）。観測のレベルが 3 以上なら、切迫（速い点滅）の判断でも津波警報と同じに扱う。CLAUDE.md の BW-S1 に例外として書き足した。観測値を使うのは、その津波予報区に津波の発表が出ている間だけにした（福島県の記録で、解除の後も古い観測で外枠が紫のままになり、ブラウザのテストで見つけた）。
- センサーのモジュールのブラウザのテスト 4 件は、Playwright 同梱のブラウザがこの PC にないため動かない（手元の Chrome を使う設定に対応していない）。今回の変更とは関係ない。Playwright なしでは 47 件すべて通る。
- 静岡県のデモ：地震（05:07、駿河湾、最大震度6弱、M6.5、深さ20km）→津波注意報 0.8m→津波警報 2m→大津波警報 5m→10m以上→津波注意報→解除。すべて模擬。最初のコマが地震だけになったので、ブラウザのテストに、デモの途中のコマへ飛ぶ口（`__shell.seekDemo`）を足した。
- テスト：app 106 件すべて通過。

## l4b へ戻す学び

- 「読めない人」向けの画面では、説明の文を消すのではなく、要約を見せて折り畳む。安全のための注意（直線の方向で道順ではない、地形で予想より高くなる）は、短い形で常に見せる。
- デモの印を画面の下にまとめるときは、いちばん上の情報にも短い印を残す。
- 描き直しの間隔を変えると、テストの待ち方が前提に入り込んでいることが分かる。
