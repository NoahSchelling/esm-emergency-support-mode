# 試作：断片入力の解析器（modules/fragment）

- 作成日：2026-11-05（日本時間）
- 置き場所：`modules/fragment/`（使い方は [modules/fragment/README.md](../../modules/fragment/README.md)）
- 状態：**試作**。解析だけをする。助言・予報・警報・危険度の判断はしない（BW-S1、BW-S4）。

## 1. 何をするものか

揺れの最中や直後に利用者が打つ短い断片から、時刻・震源の地名・規模・深さ・震度・地域名・問いを取り出す。結果は利用者の申告（`source: "user"`）で、公的に確認された情報ではない。画面に出すときは、公的な発表を優先する旨（文言は「！！仮の値！！」）を添える（BW-S2）。

## 2. 作りの方針

- 書かれていないことは足さない。読めなかった項目は `null`。
- 何も読めなければ `unknown`。「安全」「異常なし」の意味にしない（BW-S3）。
- 読み方が 2 通り以上あれば、すべて候補として返し、選ばない。
- 単位や印のない数字は読まない。印のあるものだけを読む。
- 判断を黙って行わない。推定したこと（日付、単位、年、日本時間）と、候補から外したものは `detail` と `notes` に書く。

## 3. 見逃しうる誤りの種類

解析器は正規表現と短い地名の手掛かりで読むだけで、意味は理解していない。次の誤りが起こりうる。**ここに書いた以外にもある**前提で扱う。

### 3.1 間違った値を、読めたものとして返す（いちばん危ない）

| 種類 | 例 | 何が起こるか |
| --- | --- | --- |
| 年を時刻と読む | `2026` | 20:26 の時刻として返す（年かもしれない） |
| 時刻に見える数字を時刻と読む | `1930 M5`（本当は別の量） | 19:30 として返す。4 桁の数字は、時刻として成り立てば時刻と読む |
| 深さと距離の取り違え | `5km`（震源から 5km の意味） | 深さ 5km として返す。`km` の付いた数字は深さと読む |
| 時刻の日付違い | `2330`（昨日の 23:30 のつもり） | 今日の 23:30 として返す（推定と明記する）。今日とすると未来になる場合だけ、日付を決めない |
| 日本時間以外の時刻 | 海外の時刻 | 日本時間として読む（推定と明記する） |
| 弱と強の取り違え、桁の打ち間違い | `5強`（本当は 5弱）、`M55`（M5.5 のつもり。範囲外として読まない） | 利用者の打った字をそのまま読むので、打ち間違いは直せない。`M55` のように範囲外のものは読まない |
| 手掛かりのある地名の決め打ち | `震度4 千葉` | 震度の隣の地名は地域名だけにする。実際は震源の地名だったとしても気づけない。海の名前（`沖`・`灘` など）は震源だけにする |
| 候補を外しすぎる | `震度4 5弱` | 震度が 2 つになる読みを外して、「5弱」を規模として読む。外したことは `detail` に出すが、外した方が正しいことがある |
| 地名でない語の取り込み | `都市`（`市` で終わる） | 地名として読む。`市`・`区`・`町`・`村`・`島`・`道` などの終わり方で地名と判断するため |
| `震源` の後の語の取り込み | `震源 未知数` | 漢字・カタカナだけの 2〜8 文字なら、地名として読む（`不明` など一部は除く） |

### 3.2 読むべきものを読まない（安全側の誤り）

| 種類 | 例 | 何が起こるか |
| --- | --- | --- |
| 地名の見逃し | `能登` `三陸`（地名一覧にも終わり方にも当たらない）、`千葉で揺れた`（ひとつながりの語） | 読まず、`unknown` か `unrecognized` に残る |
| 誤字・表記ゆれ | `震ど4` `震度4じゃく` `ごじゃく` `Ｍ5．5`（全角は直る）`m5,5` | 読まない。直さない |
| 幅のある書き方 | `震度5弱以上` `M7クラス` `震度5-6` | 決めつけないため読まない（`M7クラス` は `M7` だけ読み、`クラス` を `unrecognized` に残す） |
| 単位や印のない数字 | `50` `5.5` `4` | 読まない |
| 午前12時・時だけ・秒付き・「半」 | `午前12時` `8時頃` `08:46:30` `8時半` | 読まない |
| 日付の見逃し | `5日` `先週` `2月30日` | 読まない。読めない日付を書いたときは、今日で埋めない |
| 「？」の拾い過ぎ・拾い漏れ | `津波来る？` | 「？」の前の、読み取れた項目でない語をひとまとまりの問いとして残す。文の区切りが空白だけだと、問いの範囲を取り違える |
| 英語・外国語・方言・口語 | `shaking` `ゆれた` | 読まない |

### 3.3 候補の出し方による誤り

- **読み方の候補は、解析器が思いついた分だけ**。書いた人の意図が候補にないことがある。候補が複数でも「どれかが正しい」とは限らない。
- 候補の数は 16 まで。超えると `unknown`（決められなかった）にする。
- 同じ項目を複数書いた入力（`M5.5 M6.0`）は、候補を分けて返し、片方を選ばない。

### 3.4 そもそもの限界

- 入力が事実かどうかは確かめない。利用者の勘違い、いたずら、過去の地震の話でも読み取る。
- 時刻が現在から遠い過去かどうかは判断しない（同じ日の過去なら、そのまま通す）。
- 地名が実在するか、震度と地域の組み合わせが正しいかは確かめない。
- 読み取った内容から危険度を判断しない。「5弱」と読めても、それが危ないかどうかは言わない。

## 4. 試し方

```bash
node --test modules/fragment/test/*.test.js
```

ご指定の例（`0846 M5.5 d50km 最大5弱`、`16:53 三陸沖 M7.4`、`揺れた`、`津波？`、`大きい`、`震度4 千葉北東部`、`5弱`）に加え、次を試している。

- 全角の数字・英字・記号、ゼロ幅文字。
- 単位なし（`d50`、`50`、`5.5`、`d50m`）。
- 時刻と規模の取り違え（`M0846`、`M16:53`、`M8.46`、`M12`、`5.5 0846`）。
- 誤字（`震ど4`、`m5,5`、`震度8`、`震度4弱`、`震度5-6`）。
- 「？」の前の項目を申告にしないこと、複数の問い。
- 日付の推定（今日とみなす、未来になるなら決めない、読めない日付を今日で埋めない、日本時間の日付）。
- 読み取れない入力が `unknown` で、「安全」と読める言葉を `detail` に出さないこと。
- 心理的な言葉が入っていても助言を返さないこと。
- ソースが Node.js やブラウザ専用の仕組みを使っていないこと。

**まだ試していないこと**：実際の利用者の入力（模擬の入力だけで作った）。ブラウザでの読み込み（Node.js 以外で動かしていない）。文字化けした入力。
