# Skill：伝達メモの聞き取り（handoff-interview）

アプリの「Claude に相談する（伝達メモを作る）」で作った伝達メモ（Markdown）を、Claude が読み、**一度に一つずつ短く**質問して、被災の状況・困っていること・体や気持ちの不調の内容を聞き取り、**専門家に見せられる Markdown** にまとめるための Skill です。

- 想定する使い方：本人が会話しづらいとき、家族が代わりに答えるとき、現場の支援者がメモに使うとき。
- **段取りと情報の支援はします**：水・食料・電源・連絡・公的な支援の窓口・手続き。
- **医療・心の診断や助言はしません**：119・#7119・自治体の相談窓口につなぐことを優先します（BW-S4）。
- 最初に必ず「命にかかわる急ぎのことはあるか」を聞き、あれば 119 などへの電話と避難を先にするよう伝えます。

中身は [SKILL.md](SKILL.md) です。

## claude.ai に入れる

！！仮の値！！ claude.ai の画面の名前と場所は変わることがあります。2026-11-07 時点の手順です。

1. このフォルダ（`skills/handoff-interview/`）を、フォルダごと ZIP にまとめます（ZIP の中に `handoff-interview/SKILL.md` がある形）。
2. claude.ai を開き、「設定」→「機能」（Capabilities）→「スキル」（Skills）を開きます。プランや組織の設定によっては、スキルを使えないことがあります。
3. 「スキルをアップロード」から ZIP を選びます。
4. 一覧に `handoff-interview` が出て、有効になっていることを確かめます。
5. 新しい会話に、アプリでコピーした伝達メモを貼り付けるか、ダウンロードした `.md` を添付して「このメモで聞き取りをしてください」と頼みます。

## Skill がないとき

伝達メモの先頭には、Skill がない人のための短い指示文（「Claude へのお願い」）が付いています。メモを**指示文ごと**貼り付ければ、同じように頼めます。

## Claude Code で使う

リポジトリを開いた Claude Code では、`skills/handoff-interview/` を `.claude/skills/` にコピーすると使えます（このリポジトリでは、開発の道具と分けるためにコピーしていません）。

## 注意

- 伝達メモと聞き取りのまとめには、健康や家族のことなど、人に知られたくない内容が入ります。渡す前に、渡してよい内容か確かめてください。不要になったら、アプリの「内容削除」と会話の削除で消してください。
- まとめは聞き取りの記録です。診断・助言ではありません。
