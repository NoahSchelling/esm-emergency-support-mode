# modules/fragment：断片入力の解析

揺れの最中や直後に、利用者が打つ短い断片（例：`0846 M5.5 d50km 最大5弱`）から、時刻・震源の地名・規模・深さ・震度・地域名・問いを取り出します。**解析だけ**をします。助言、予報、警報、危険度の判断はしません。

## 公的情報を優先してください

！！仮の値！！ このモジュールが返すのは、**利用者が自分で打った内容を機械的に読み取った結果**です。公的に確認された情報ではありません。避難や身の安全にかかわる判断は、気象庁・自治体などの公的な発表と指示を優先してください。読み取りは間違うことがあります（見逃しうる誤りは [docs/proto/fragment.md](../../docs/proto/fragment.md)）。

## 使い方

素の JavaScript（ES モジュール）です。外部ライブラリは使いません。ブラウザでも Node.js でもそのまま読み込めます（ブラウザ専用の部分はありません）。

```js
import { parseFragment } from './modules/fragment/index.js';

const result = parseFragment('0846 M5.5 d50km 最大5弱');
```

Node.js でファイルとして読むときは、このディレクトリの `package.json`（`"type": "module"`）が効きます。

### 引数

`parseFragment(input, options)`

| 引数 | 意味 |
| --- | --- |
| `input` | 利用者の入力（文字列。200 文字まで） |
| `options.now` | 現在時刻（`Date`・ISO 8601 の文字列・ミリ秒）。省略すると今。テストと再生用 |
| `options.assumeToday` | 日付がないとき「今日」とみなすか。既定は `true` |
| `options.simulated` | `true` にすると `source` を `"simulated"` にする（模擬・再生データ用） |

### 返り値

共通の形で返します。

```js
{
  kind: 'fragment',
  status: 'ok',                       // ok | unknown | unsupported | error
  value: { ... },                     // status が ok のときだけ。それ以外は null
  observed_at: '2026-11-05T18:00:00+09:00',  // 解析した時刻（日本時間）
  source: 'user',                     // 利用者の申告。模擬のときは 'simulated'
  detail: '…',                        // 人が読む日本語の補足
}
```

| status | いつ返すか |
| --- | --- |
| `ok` | 項目か問いを 1 つ以上読み取れた |
| `unknown` | 何も読み取れなかった（空、「揺れた」「大きい」など）。**「安全」「異常なし」の意味ではない**。読み方が多すぎて決められなかったときもこれ |
| `unsupported` | 200 文字を超える入力（このモジュールは短い断片だけを読む） |
| `error` | 入力が文字列でない、`now` が読めない |

`value`（`ok` のとき）：

| キー | 中身 |
| --- | --- |
| `input` | 入力そのまま |
| `readings` | **読み方の候補の配列**（1 件以上）。順序に優先の意味はない |
| `ambiguous` | 候補が 2 件以上なら `true` |
| `question` | 「？」付きの問い。なければ `null`。あれば `{ texts: ['津波'] }`（「？」だけなら `texts` は空） |
| `unrecognized` | 読み取れなかった部分（入力のまま） |
| `notes` | 読み取りに関する補足（日本語） |
| `officiallyConfirmed` | 常に `false` |

`readings` の各要素は、次の 6 項目を持ちます。読み取れなかった項目は `null` です。

| 項目 | 形 |
| --- | --- |
| `time` | `{ date, dateBasis, hour, minute, text, iso }`。`dateBasis` は `input`（日付の記載あり）、`input-year-assumed`（年を今年と推定）、`assumed-today`（日付がないので今日と推定）、`relative-word`（「今日」「昨日」の語）、`unresolved`（今日とすると未来になるので決めない）、`null` |
| `epicenter` | 震源の地名（文字列） |
| `magnitude` | `{ value, qualifier }`。`qualifier` は「5弱」を規模として読んだときの `弱` / `強`。それ以外は `null` |
| `depth` | `{ km, unitAssumed }`。`d50` のように単位がないときは `unitAssumed: true`（km と推定） |
| `intensity` | `{ scale, max }`。`scale` は `0`〜`7`、`5弱` `5強` `6弱` `6強`。`max` は「最大」と書かれたとき `true` |
| `area` | 地域名（文字列） |

### 読み方が複数あるとき

`5弱` だけの入力は、震度の 5弱とも、規模の 5 とも読めます。どちらかに決めず、両方を `readings` に入れます。

```js
parseFragment('5弱').value.readings;
// [ { intensity: { scale: '5弱', max: false }, magnitude: null, ... },
//   { intensity: null, magnitude: { value: 5, qualifier: '弱' }, ... } ]
```

地名も同じです。手掛かり（`沖`・`灘` など海の名前、`震源` の語、`震度` の隣）がなければ、震源と地域名の両方を候補にします。画面に出すときは、候補をすべて見せるか、「読み取れない」と出してください。1 つを選んで見せないでください。

### 日付の推定

日付がなく時刻だけのとき、今日（日本時間）とみなします。この推定は `time.dateBasis` が `assumed-today` になり、`detail` にも書きます。今日とすると現在より先の時刻になるときは、昨日かもしれないので日付を決めません（`unresolved`）。

## 読み取れる書き方

| 項目 | 例 |
| --- | --- |
| 時刻 | `0846` `08:46` `8時46分` `午後4:30` `4:30 PM`（日本時間として読む） |
| 日付 | `2026-11-04` `11/4` `11月4日` `昨日` `今日` |
| 規模 | `M5.5` `M 5.5` `マグニチュード5.5` `規模5.5`（0 を超え 10 以下） |
| 深さ | `d50km` `d50` `深さ50km` `50km` `50キロ`（0〜800 km） |
| 震度 | `震度4` `震度5弱` `最大5弱` `最大震度は5強` `震度五弱` `震度5-`（5弱）`震度6+`（6強） |
| 震度か規模か分からない | `5弱` `5強` `6弱` `6強`（両方を候補にする） |
| 震源 | `三陸沖` `日向灘` `震源は千葉県東方沖` `震源 能登` |
| 地域名 | `千葉北東部` `震度4 千葉北東部` `三陸沿岸` |
| 問い | `津波？` `余震は?` `M7.4?`（「？」の前の項目は申告にせず、問いとして残す） |

全角の数字・英字・記号、ゼロ幅文字は読み取る前に整えます。**単位や印のない数字は読みません**（`50`、`5.5` だけでは項目に入れない）。読めなかった部分は `unrecognized` に入れます。

## 守っていること

- **BW-S1**：入力にない事実を足さない。危険度を判断しない。独自の予報・警報を出さない。
- **BW-S3**：読み取れない入力は `unknown`。「揺れた」だけの入力でも、安全かどうかを判断しない。`detail` に「判断はしていません」と常に書く。
- **BW-S4**：「怖い」などの心理的な言葉が入っていても、助言を返さない（`unrecognized` に残るだけ）。心理・医療の助言を将来つなぐ場合のための入口は、この回では作っていない。**このモジュールは解析だけで、助言の処理を持たない**。
- 位置などの個人の情報を扱わない。解析はすべて端末の中で終わり、通信しない。

## テスト

Node.js 標準の `node --test` を使います（Node.js 22 で確認）。

```bash
node --test modules/fragment/test/*.test.js
```

ご指定の例、全角数字、単位なし、時刻と規模の取り違え、誤字、複数の読み方、日付の推定、「読み取れないものは `unknown`」などを試しています。見逃しうる誤りは [docs/proto/fragment.md](../../docs/proto/fragment.md) にまとめています。
